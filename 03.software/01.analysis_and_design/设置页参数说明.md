# 放风机设置页参数说明

屏上代号显示在湿度数码管，数值显示在温度数码管。  
长按设置键进入设置页，短按设置键切换下一项。

对应固件：`04.controller_unit_motor_freertos`（`app/gui/gui.cpp`）。

## 全部参数

| 显示 | 含义 | 单位/取值 | 范围 | 说明 | 当前是否显示 |
|------|------|-----------|------|------|--------------|
| **a1** | 温度报警上限 | ℃ | 0～55，且 > a2 | 超温报警 | 是 |
| **a2** | 温度报警下限 | ℃ | 0～55，且 < a1 | 低温报警 | 是 |
| **p0** | 温控模式 | 1 / 2 | 1=中心温控，2=限值温控 | 切换自动温控算法 | **否**（`GUI_ENABLE_P0_P3_SETTING=0`） |
| **p1** | 目标中心温度 | ℃ | 0～55 | 中心温控用 | 是 |
| **p2** | 温度正回差 | ℃ | 0～5 | 升温侧回差 | 是 |
| **p3** | 温度负回差 | ℃ | 0～5 | 降温侧回差 | **否**（`GUI_ENABLE_P0_P3_SETTING=0`） |
| **p4** | 温度补偿 | ℃（0.1℃步进） | −9.0～+9.0 | 传感器修正，可显示负号 | 是 |
| **p5** | 开启温度上限 | ℃ | 0～55，且 > p6 | 自动模式：≥此温全开 | 是 |
| **p6** | 关闭温度下限 | ℃ | 0～55，且 < p5 | 自动模式：≤此温全关 | 是 |
| **d1** | 定时段1 | 时刻 + 开度% | 时 0～23；开度 0～100 | 定时模式第1段 | **否**（`GUI_ENABLE_D1_D4_SETTING=0`） |
| **d2** | 定时段2 | 同上 | 同上 | 定时模式第2段 | **否** |
| **d3** | 定时段3 | 同上 | 同上 | 定时模式第3段 | **否** |
| **d4** | 定时段4 | 同上 | 同上 | 定时模式第4段 | **否** |
| **c1** | 电机行程总圈数 | 圈 | 1～999 | 满行程圈数；精确下发最大圈数即为此值；校准可写入 | 是 |
| **c2** | 一圈时间 | 秒/圈 | 5～100 | 目标时间 ≈ 圈数 × c2 | 是 |
| **s0** | 数据上报间隔 | 分钟 | 5～30 | MQTT 周期上报 | 是 |
| **s2** | 本地报警开关 | 0 / 1 | 0=关，1=开 | 蜂鸣等本地报警 | 是 |

## 当前机上可翻到的顺序

```
a1 → a2 → p1 → p2 → p4 → p5 → p6 → c1 → c2 → s0 → s2
```

（p0、p3、d1～d4 被宏关掉，切换时自动跳过）

## 相关计算

- 满行程时间 ≈ **c1 × c2** 秒  
- 精确下发 N 圈的目标时间 ≈ **N × c2** 秒  
- 断电保存的行程计时按**整秒**落盘  

## 开关宏（gui.cpp）

| 宏 | 默认 | 作用 |
|----|------|------|
| `GUI_ENABLE_D1_D4_SETTING` | 0 | 1=显示 d1～d4 |
| `GUI_ENABLE_P0_P3_SETTING` | 0 | 1=显示 p0、p3 |
