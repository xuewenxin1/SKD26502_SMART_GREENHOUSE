# SKD26502 大棚智能温湿度计和放风机

> **最近改了什么、主要在哪个文件夹？** 请看 [`修改说明_README.md`](修改说明_README.md)。

| 按键 | 作用 |
|------|------|
| **F7** | 编译并烧录放风机（`04.controller_unit_motor_freertos`） |
| **F8** | 编译并烧录温湿度计（`04.controller_unit_sensor_freertos`） |
| 终端任务 `Build All` | 两个固件都编译 |

烧录用 `pyocd`，芯片 `py32f071xb`。请先接好调试器再按 F7 或 F8。

产物在各自工程的 `build` 目录：`SKD26502_SMART_GREENHOUSE.hex` / `.bin` / `.elf`。

需要本机已安装：CMake、Ninja、Arm GNU Toolchain `arm-none-eabi-gcc`、`pyocd`。

开机先关窗。找零这段时间屏幕一直显示 0%。关窗时关灯亮、继续供电。要连续 3 次测到电流为 0，才认为到零点：这时才停电机、断电、关灯灭。中间只要有一次电流不是 0，就重新数，电机不停。完成后再按记忆开度开窗，屏幕才从 0% 往上走到记住的开度。改 C1 行程后仍停在 0%，不会自动再开回去。关到限位：电流为 0 并停住后断电、关灯灭。再按开时，开度会马上从 0% 往上走。首页短按设置键是暂停；开/关键在任意模式下都能用，暂停之后也可以再开再关。电机在转时对应的开/关灯亮；到 0% 关灯灭，到 100% 开灯灭，停下也灭。开到 100% 或关到 0% 后电机会停；这时直接按开或关即可，不用先按停。只有电机真正停住大约 0.5 秒后，才会把开度写进 Flash。转动过程中不记忆；中途断电不会记住跑到一半的位置，下次开机仍按上一次停稳的开度走。发给小程序的开度联网成功后才会发。开机大约 10 秒后按原版方式连 4G：先 AT，再读 IMEI/SIM，再连 MQTT。连上后会按 `greenhouse/IMEI/up/dev` 上报设备信息：1 字节类型（放风机 1、温湿度计 2）、15 字节 IMEI、20 字节卡号、1 字节校验和。成功会打印 `Get IMEI OK`、`MQTT connect OK`、`Report device info`、`Report opening`。联网失败不会影响开关风机。

设置页 C1 行程时间最短 30 秒，最长 999 秒。自动校准结果也会限制在这个范围。

电机电流为 0 并且已经停住时，如果开度只差一点点不到头，就当成到限位，显示改成 0% 或 100%。关到 0% 或开到 100% 后电机会停、开关灯会灭；这时直接按开或关即可，不用先按停。

设置页加减键：短按每次变 1，长按每次变 10（按住会连续跳）。开关类项目仍是切换。回差 P2 只能设 0、1、2、3、4、5℃，加减每次只变 1，出厂默认 0℃。S0 数据上报间隔可调 **5～30** 秒（默认 5），退出设置后写入 Flash。设置页 D1～D4、P0、P3 暂时隐藏；以后要显示时，把 `gui.cpp` 里的 `GUI_ENABLE_D1_D4_SETTING` / `GUI_ENABLE_P0_P3_SETTING` 改成 `1` 再编译。

按行程时间开合；关窗不会因为电流抖动直接跳成 0%。

温湿度计首页不显示开度、百分号和 OK。BAT_C（PB15）一直拉高，ADC 基准 3.6V，电量按 1.8V=空、2.1V=满（约 2.08V 应接近满格）。请用 **F8** 烧录温湿度计。

自动模式：把工作模式调到自动。实测温度比设定目标（P1）高得越多，放风机开度越大。温度和温差都只看整数℃，小数直接丢掉，不四舍五入（例如 26.9℃ 当成 26℃）。回差 X（P2，0～5℃）会把整条曲线往后挪：温差不超过 0+X℃ 时开度 0%；超过 2+X℃ 开 20%；超过 4+X℃ 开 40%；依此类推，超过 10+X℃ 开 100%。X 为 0 时：0℃→0%，10℃→100%。实测不高于目标时关到 0%。请按 **F7** 烧录放风机。

温度高于 A1 上限或低于 A2 下限时，PA12 输出约 4kHz 方波让蜂鸣器响；回到范围内就停。S2 本地报警关掉则不响。温度只看整数℃。**NTC 和温湿度计都不插、显示 `---` 时：同样蜂鸣并亮告警。** MQTT 状态帧故障码：`1` 电机过流，`2` 传感器故障（无有效温度），`3` 温度超限（超出 A1/A2）；优先级 1>2>3。放风机按 **F7**，温湿度计按 **F8**。

传感器选用：都插时温度用 NTC、湿度用温湿度计；只插温湿度计则用它的温湿度；只插 NTC 则只有温度、湿度不显示；都不插则温度湿度显示 `---` 并报警。NTC 温度按 **B 值法**计算（B=3950、R25=10kΩ、串联上拉 10kΩ）。**P4** 在实测温度上加减补偿（0.1℃ 步进），已作用于显示、报警、自动模式、MQTT。

电机自动校准：往返都按真实走到限位才停，不再因软件开度计时提前停；校准结束后才写入 C1 行程。App 强制开/关期间不做堵转停机；中途若已停住不再自动重试，保持当时开度。软件过流保护已关闭。用户停、软件开度到 0%/100%、电流≈0 限位仍会停。
