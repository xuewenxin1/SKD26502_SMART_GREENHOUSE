烧录用 `pyocd`（驱动 ST-Link），芯片 `py32f071xb`。请先接好调试器再按 F7 或 F8。

产物在各自工程的 `build` 目录：`SKD26502_SMART_GREENHOUSE.hex` / `.bin` / `.elf`。

**电脑什么都没装时（只烧录，不编译）：**  
打开文件夹 **`烧录包`**（可整夹拷走），看里面的 `使用说明.txt`：  
1）第一次双击 `setup_flash_env.bat`  
2）插 ST-Link、板子上电  
3）双击 `flash_motor.bat`（烧 `SKD26502_motor.bin`）或 `flash_sensor.bat`（烧 `SKD26502_sensor.bin`）  

重新编译后，在烧录包里运行 `sync_bins_from_build.bat` 可更新这两个 bin。

日常开发编译仍需要：CMake、Ninja、Arm GNU Toolchain `arm-none-eabi-gcc`；烧录另需 ST-Link。

开机不主动转、不归零：按 Flash 里上次停稳的开度记住位置，电机保持不动，屏幕直接显示该开度。改 C1 行程圈数后仍会先关到 0%，不会自动再开回去。关到限位：电流为 0 并停住后断电、关灯灭。再按开时，开度会马上从 0% 往上走。首页短按设置键是暂停；开/关键在任意模式下都能用，暂停之后也可以再开再关。电机在转时对应的开/关灯亮；到 0% 关灯灭，到 100% 开灯灭，停下也灭。开到 100% 或关到 0% 后电机会停；这时直接按开或关即可，不用先按停。只有电机真正停住大约 0.5 秒后，才会把开度写进 Flash。转动过程中不记忆；中途断电不会记住跑到一半的位置，下次开机仍按上一次停稳的开度显示（也不主动去转）。发给小程序的开度联网成功后才会发。开机大约 10 秒后按原版方式连 4G：先 AT，再读 IMEI/SIM，再连 MQTT。连上后会按 `greenhouse/IMEI/up/dev` 上报设备信息：1 字节类型（放风机 1、温湿度计 2）、15 字节 IMEI、20 字节卡号、1 字节校验和。成功会打印 `Get IMEI OK`、`MQTT connect OK`、`Report device info`、`Report opening`。联网失败不会影响开关风机。

设置页 **C1** 为行程**圈数**（1～999），**C2** 为**一圈秒数**（10～100，默认 25）。满行程时间 = C1×C2（例如 C1=3、C2=25 → 约 75 秒）。自动校准按当前 C2 把测得秒数换算成圈数写入 C1。旧板若 C1 仍是秒数（大于 99），开机加载时会按 C2 换算成圈数。

电机电流为 0 并且已经停住时，如果开度只差一点点不到头，就当成到限位，显示改成 0% 或 100%。关到 0% 或开到 100% 后电机会停、开关灯会灭；这时直接按开或关即可，不用先按停。

设置页加减键：短按每次变 1，长按每次变 10（按住会连续跳）。开关类项目仍是切换。回差 P2 只能设 0、1、2、3、4、5℃，加减每次只变 1，出厂默认 0℃。S0 数据上报间隔可调 **5～30** 秒（默认 5），退出设置后写入 Flash。设置页 D1～D4、P0、P3 暂时隐藏；以后要显示时，把 `gui.cpp` 里的 `GUI_ENABLE_D1_D4_SETTING` / `GUI_ENABLE_P0_P3_SETTING` 改成 `1` 再编译。

按行程圈数×每圈秒数（C1×C2）开合；关窗不会因为电流抖动直接跳成 0%。

温湿度计首页不显示开度、百分号和 OK。BAT_C（PB15）一直拉高，ADC 基准 3.6V，电量按 1.8V=空、2.1V=满（约 2.08V 应接近满格）。请用 **F8** 烧录温湿度计。

自动模式：把工作模式调到自动。按设置页 **P5 上限 / P6 下限** 带回差控制（整数℃）：温度 **≥ P5** 时全开；温度 **≤ P6** 时全关；**P6～P5 之间保持原状**（升温未到上限不开，降温未到下限不关）。例如 P6=20、P5=25：早晨 18℃关着 → 升到 20～24℃仍关 → 到 25℃全开 → 再到 30℃仍开 → 回落到 25℃仍开 → 降到 20℃才全关。默认 P5=25、P6=20；温度可设 0～55℃，且上限必须比下限高至少 1℃。**A1/A2** 仍只用于超限蜂鸣报警。请按 **F7** 烧录放风机。

温度高于 A1 上限或低于 A2 下限时，PA12 输出约 4kHz 方波让蜂鸣器响；回到范围内就停。S2 本地报警关掉则不响。温度只看整数℃。**NTC 和温湿度计都不插、显示 `---` 时：同样蜂鸣并亮告警。** MQTT 状态帧故障码：`1` 电机过流，`2` 传感器故障（无有效温度），`3` 温度超限（超出 A1/A2）；优先级 1>2>3。放风机按 **F7**，温湿度计按 **F8**。

传感器选用：都插时温度用 NTC、湿度用温湿度计；只插温湿度计则用它的温湿度；只插 NTC 则只有温度、湿度不显示；都不插则温度湿度显示 `---` 并报警。NTC 温度按 **B 值法**计算（B=3950、R25=10kΩ、串联上拉 10kΩ）。**P4** 在实测温度上加减补偿（0.1℃ 步进），已作用于显示、报警、自动模式、MQTT。

电机自动校准：往返都按真实走到限位才停，不再因软件开度计时提前停；校准结束后才写入 C1 行程。App 强制开/关期间不做堵转停机；中途若已停住不再自动重试，保持当时开度。软件过流保护已关闭。用户停、软件开度到 0%/100%、电流≈0 限位仍会停。
